# Agent Instructions

## Project

SongDrop is a Telegram-first music platform.

Before working on the project, read:

- `README.md`
- `docs/PRODUCT.md`
- `docs/ARCHITECTURE.md`

## Development

- Runtime: Node.js 24 LTS
- Language: TypeScript
- Package manager: pnpm
- Telegram framework: grammY
- Use strict TypeScript.
- Keep implementations as small as the current task allows.
- Do not introduce infrastructure or dependencies for hypothetical future needs.

## Verification

For code changes, run:

```bash
pnpm typecheck
```
